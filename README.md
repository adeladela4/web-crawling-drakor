# Web Crawling Data Drama Korea

Proyek pengumpulan dan pengolahan data drama Korea menggunakan teknik web crawling dengan Python. Data yang diperoleh kemudian disimpan dalam bentuk dataset untuk digunakan dalam proses analisis lebih lanjut.

## Teknologi yang Digunakan
- Python
- Pandas
- Jupyter Notebook / Google Colab

## Tahapan Pengerjaan
- Mengumpulkan data drama Korea melalui proses crawling.
- Mengolah dan membersihkan data.
- Menggabungkan data ke dalam dataset.
- Menyimpan hasil pengolahan dalam format CSV.

## Dataset
Hasil pengolahan data disimpan dalam file `Drakor_merge.csv`.

## Menjalankan Project
Buka notebook atau file Python melalui Google Colab atau VS Code sesuai struktur project.
